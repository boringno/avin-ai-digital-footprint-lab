# 順風醫美 LINE AI 客服後台操作說明

**適用角色：** 真人客服、諮詢師、店長

## 這個後台做什麼

AI 會先回答常見問題、收集預約資料；需要真人確認的案件會進入後台。真人客服在這裡接手後，AI 會暫停，不會與客服同時回覆客人。

## 登入

1. 開啟 `https://line-ai-live-demo.vercel.app/admin/login`。
2. 輸入管理員建立的工作帳號與密碼。
3. 登入後會進入「真人客服接手工作台」。

請勿共用帳密。離開座位前請按右上角「登出」。

## 工作台：處理待真人案件

進入 `/admin/workbench` 後：

1. 左側「待接手佇列」會優先顯示待處理案件。
2. 點選一張案件卡，右側可查看客人、AI 與真人客服的完整對話。
3. 先讀取「原因」與最末一則客人訊息，再確認右側的預約線索。
4. 要由真人處理時，按「接手」。畫面顯示「真人接手中」後，AI 不會再自動回覆該客人。
5. 在下方輸入框輸入回覆並送出；客人會直接在 LINE 收到訊息。
6. 真人處理完成、可恢復一般 AI 問答時，按「還給 AI」。

### 重要規則

- 客人正在由真人處理時，不要按「還給 AI」，除非該問題已處理完畢。
- 涉及術後明顯不適、醫療判斷、價格最終確認、客訴時，應維持真人接手，不要急著交回 AI。
- AI 已接住基本問題時，真人可直接延續對話，不需要重新問一次客人已提供的療程、館別或時段。
- 系統會優先顯示客人在 LINE 設定的暱稱；若客人已提供稱呼，預約線索會優先顯示該稱呼。若僅顯示一串縮寫 ID，代表 LINE 暱稱尚未同步，請用對話內容或官方 LINE OA 對照確認。

## 預約線索看板：追蹤進度

按右上角「預約線索」，或開啟 `/admin/leads`。

每張卡會顯示：療程、館別、時段、電話、負責人與客服備註。

### 建議操作順序

1. 新客進來後，先按「指派給我」，讓其他客服知道由誰跟進。
2. 已聯絡客人後，把狀態改成「已聯繫」。
3. 確認實際預約時，把狀態改成「已預約」，並在備註填入日期、時間、館別或注意事項。
4. 到店後改成「已到店」。
5. 最終改成「成交」或「流失」；流失請簡短記錄原因，例如「價格考量」、「時間無法配合」、「未回覆」。

### 狀態定義

| 狀態 | 使用時機 |
| --- | --- |
| 新進線 | AI 或客服剛收到需求，尚未人工聯絡。 |
| 已聯繫 | 真人客服已開始聯絡或回覆。 |
| 已預約 | 日期、時間、館別已由真人確認。 |
| 已到店 | 客人已完成到店。 |
| 成交 | 已完成本次成交。 |
| 流失 | 本次未成交，請保留簡短原因。 |

## 客服話術原則

- 先回答客人的問題，再自然邀請預約；不要一開始就要求留資料。
- AI 的內容是初步協助。真人確認價格、可約時段、個人療程適合度與醫療相關問題。
- 不承諾療效、不保證效果、不替客人做醫療判斷。
- 若客人已提供療程、館別或時段，直接延續，不要重複詢問。

## 異常處理

### 畫面出現「讀取預約線索失敗」

1. 先不要變更卡片狀態或以為更新已儲存。
2. 按「重新整理」一次；仍失敗時重新登入後再試。
3. 若還是失敗，截圖保留畫面、記下時間與客人 LINE 顯示名稱，交給系統維護人員。
4. 在問題排除前，可回到官方 LINE OA 先人工回覆，避免客人久候。

### 無法送出真人訊息

1. 確認網路正常並重新整理工作台。
2. 不要快速連按送出，避免重複傳訊息。
3. 若畫面顯示失敗，保留截圖與送出時間，改由 LINE OA 後台人工補回覆，並通知維護人員。

### AI 回覆不正確或資料過期

1. 真人先接手並提供正確資訊給客人。
2. 在預約線索備註記下「錯誤問題、正確答案、發生時間」。
3. 交給維護人員更新診所核准資料、活動內容或話術；未確認前不要讓 AI 自由猜測。

## 每日交班建議

1. 檢查「新進線」與待接手佇列是否還有未處理案件。
2. 確認今天的「已預約」均已補上日期、時間與館別。
3. 將未完成案件指派給明確負責人。
4. 將 AI 回覆錯誤、客人常問的新問題、活動異動集中記錄給維護人員。

## 系統邊界

- 目前真人客服應從本後台接手與回覆，系統才能確實暫停 AI。
- 直接在 LINE OA 後台手動回覆，系統目前不一定能自動辨識為真人接手。
- 後台資料是作業依據；若另有 Google Sheets，Sheets 目前僅適合作為報表快照，不應作為預約進度的唯一依據。
